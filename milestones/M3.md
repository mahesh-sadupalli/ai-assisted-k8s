# Milestone 3 — AWS EKS + networking / ingress

Full spec lives in `../README.md` → **Milestones → M3**. This is the working checklist.

## Build
- [x] **Terraform** (`infra/terraform`): VPC (2 AZs, private nodes, single NAT), EKS with a managed node group, EKS access entries, ECR (immutable tags, scan on push, lifecycle), S3 remote state with native lockfile
- [x] Ingress: ingress-nginx behind an AWS NLB, Ingress for the control-plane API and `hello` (`infra/k8s-eks`)
- [x] Images built for `linux/amd64` and pushed to ECR (`make eks-push`)
- [x] `agent/` v2: `agent plan <plan.json>`. Deterministic rules plus a Claude review; exits 1 on `block`

## Run it on AWS (costs money: EKS ~$0.10/h + 2× t3.medium + NAT ~$0.05/h)
```bash
cp infra/terraform/backend.hcl.example infra/terraform/backend.hcl   # set your bucket
make eks-up          # terraform apply + kubeconfig
make eks-push        # build + push images to ECR
make eks-deploy      # ingress-nginx, manifests, prints the ingress URL
make eks-destroy     # ALWAYS when done: removes the NLB first, then terraform destroy
```

Review your own plan before applying:
```bash
terraform -chdir=infra/terraform plan -out=plan.out
terraform -chdir=infra/terraform show -json plan.out > plan.json
go run ./agent plan plan.json
```
