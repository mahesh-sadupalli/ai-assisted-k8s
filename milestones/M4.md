# Milestone 4 — CI/CD with GitHub Actions

Full spec lives in `../README.md` → **Milestones → M4**. This is the working checklist.

## Build
- [x] `ci.yml`: lint + race tests + terraform validate + image builds on every PR
- [x] `deploy.yml`: test gate → OIDC to AWS → ECR push → EKS deploy, on merge to `main`
- [x] Least-privilege GitHub OIDC role (Terraform): `main` of this repo only, ECR push to 2 repos, edit rights in `sentinel-system` only
- [x] Post-deploy **behavioural** smoke test (`scripts/smoke.sh`): 404 / 400 / guardrail 403
- [x] **Rollback trigger** (`scripts/deploy.sh`): failed rollout or smoke → `kubectl rollout undo`
- [x] `agent/` v3: `agent deploy-review <report> [diffstat]`. A failed check forces `rollback=true`; a diff over 500 lines is never "low"
- [x] Claude in CI via **Workload Identity Federation** (GitHub OIDC token), with an API-key fallback
