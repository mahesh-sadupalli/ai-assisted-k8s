# Milestone 1 — Go control-plane API + first agent

Full spec lives in `../README.md` → **Milestones → M1** (goal, what gets built, AI focus, skills, done-when). This is the working checklist.

## Build
- [ ] Go HTTP API: `POST /deployments`, `GET /deployments/{id}`
- [ ] Request validation + **one real guardrail** (per-namespace resource quota, or reject a disallowed image registry / missing resource limits)
- [ ] Persistence for deployment intents (SQLite / in-memory) + structured logging
- [ ] `agent/` v0: log snippet → structured summary (*what broke → likely cause → next step*) via Claude API tool use
- [ ] Unit tests for guardrail + validation

## Done when
- An invalid request is rejected by the guardrail with a clear error; a valid one is accepted and retrievable.
- `agent summarize <logfile>` returns a structured summary.
- Unit tests pass.
