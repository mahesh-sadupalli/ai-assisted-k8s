# Milestone 1 — Go control-plane API + first agent

Full spec lives in `../README.md` → **Milestones → M1** (goal, what gets built, AI focus, skills, done-when). This is the working checklist.

## Build
- [x] Go HTTP API: `POST /deployments`, `GET /deployments/{id}`
- [x] Request validation + **one real guardrail** (per-namespace resource quota, or reject a disallowed image registry / missing resource limits)
- [x] Persistence for deployment intents (in-memory) + structured logging
- [x] `agent/` v0: log snippet → structured summary (*what broke → likely cause → next step*) via Claude API tool use
- [x] Unit tests for guardrail + validation

## Done when
- An invalid request is rejected by the guardrail with a clear error; a valid one is accepted and retrievable.
- `agent summarize <logfile>` returns a structured summary.
- Unit tests pass.

## Notes / evidence
- Guardrail rejects `docker.io/evil:1` with `403 rejected by guardrail: image ... is not from an allowed registry`; a valid request returns `201` and is retrievable via `GET /deployments/{id}`.
- `go test ./...` passes (validation, guardrail quota/registry, store, HTTP handlers).
- `agent summarize agent/testdata/oomkilled.log` uses a strict `report_diagnosis` tool.
